# iMeeting · 说明书站

> 用规则，改变开会的文化。

iMeeting 的产品说明书 / 官网原型。整站是一套静态页面：整屏翻页、全屏流体底纹随翻屏换色、左文右图交替，用图形化叙事替代文字堆叠。

## 页面结构

| 路由 | 页面 | 主要内容 |
|---|---|---|
| `#/` | 首页 | 两种去向对比 → 每场会都有四样东西 → 一个想法四条出路 → 一场会的完整生命 → 表决通过即生效 → 三个入口 |
| `#/time` | 之一 · 时间 | 时间从三个缺口漏走 · 22 分钟发言轨道回放 · 四个机制 |
| `#/order` | 之二 · 秩序 | 四个声音的路由图 · 表决三环节 · 四个机制 |
| `#/continuity` | 之三 · 连续 | 决议卡 · 一笔捐赠的两条走法 · 会议时间线 · 四个机制 |
| `#/guide` | 参会引导 | 会场四要素 · 五个常用动作 · 处境→出口 · 表决三环节 · 散会之后 |
| `#/organizer` | 组织者手册 | 议程轨道 · 会议类型 · 机制参数 · 萝卜丁与治理费用 · 会后产出 |

更多截图见 [`preview/`](preview/)。

## 本地查看

直接双击 `index.html` 就能打开（零网络依赖，断网可用）。或起一个本地服务：

```bash
./tools/serve.sh        # 默认 8080 端口，局域网内其他人也能访问
```

## 修改内容

站点用 React 编写，但**不需要 Node**：源码是 `.jsx`，用随附的 esbuild 原生二进制编译成 `.js`。

```bash
./tools/get-esbuild.sh   # 首次：下载 esbuild（约 4MB，之后可复用）
./tools/build.sh         # 改完 .jsx 后编译
```

| 文件 | 作用 |
|---|---|
| `assets/app.jsx` | 路由、整屏翻页、每屏背景配色 |
| `assets/pages.jsx` | 首页、之一·时间、之二·秩序 |
| `assets/pages2.jsx` | 之三·连续、参会引导、组织者手册 |
| `assets/components.jsx` | 全部组件与图形（SVG / HTML 图形都在这里） |
| `assets/site.css` | 设计系统与全部样式 |

React、ReactDOM、GSAP、matter.js 已本地化在 `assets/vendor/`，不依赖任何 CDN。

## 说明
